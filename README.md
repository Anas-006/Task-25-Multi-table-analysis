# Task 25 – Multi-Table Sales Analysis

## Objective

The objective of this task is to perform multi-table sales analysis using SQL, Excel, and Power BI.

## Tools Used

- MySQL
- Microsoft Excel
- Power BI
- GitHub

## Dataset

Northwind sample sales database.

## Tables Used

- Orders
- Order Details
- Products

## SQL Analysis

The following analysis was performed:

1. Total Sales
2. Total Quantity
3. Total Orders
4. Average Line Sales
5. Sales by Product
6. Monthly Sales
7. Quantity by Product
8. Multi-table JOIN validation

## Power BI Dashboard

The dashboard contains:

- Total Sales KPI
- Total Orders KPI
- Total Quantity KPI
- Average Line Sales KPI
- Sales by Product
- Monthly Sales Trend
- Quantity by Product
- Product Filter
- Order Date Filter

## Key Results

- Total Sales: 68,137
- Total Orders: 40
- Total Quantity: 2,942
- Average Line Sales: 1,174.77

## Outcome

The project demonstrates practical skills in SQL joins, sales calculations, aggregation, Excel data handling, and Power BI dashboard creation.
